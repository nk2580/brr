Scope configurable colors to the permanent rail only and preserve explicit saved choices. Rail icons, hover, selection and focus follow its palette. The 52px icon rail stays mounted; the adjacent 330px sidebar has a rounded top-left corner and collapses independently. Chat fills the remaining width, including the released sidebar space. The shared toolbar control targets that menu; collapsing releases its width to the main section. Home's chat menu stays hidden while Agents or Plugins is selected. Section headers and content sit inline beside their menus.
- Native system sans-serif typography for the conversation and Brr heading; system monospace at 16px for sidebar navigation and chat titles (14px at the native minimum). Projects use folder disclosure rows with indented chat children; Recents show the saved conversations. Long titles truncate. The fixed rail contains Home, Agents and Plugins at the top, with the user profile avatar followed by a Settings gear at the bottom. All five have hover and keyboard-focus tooltips. They select destinations or open the profile independently of sidebar visibility; they never collapse the sidebar. The profile opens a dismissible menu without changing the sidebar.
- Model and reasoning controls sit inside the rounded composer, immediately before Send, with native text selectors and paired up/down chevrons matching the supplied ChatGPT desktop reference. Project/access controls occupy the preceding composer row; Plan remains on the left of the action row.
- Use the existing Button primitive and lucide icon vocabulary. Keyboard focus uses the existing outline; disabled and pending actions remain visibly distinct.

Appearance settings use named native radio choices and local-device persistence, with a Graphite fallback for absent or invalid preferences. No generated raster assets, display typography or decorative animation are needed.
- Composer controls fit the 800x600 native window in either sidebar state without hiding Send or Stop. Only the dedicated toolbar toggle expands/collapses the adjacent sidebar; its saved state, draft and active transcript are preserved. New chat and Search live inside the sidebar. Home returns to the current conversation and retains its draft and sidebar state. Repeated Agents, Plugins and Settings clicks stay in the chosen section. The whole rail remains visible and unchanged in either layout.
