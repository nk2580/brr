# Governance

Brr is currently maintained by its original project maintainer. The maintainer
coordinates releases, reviews contributions, and makes project decisions, with
discussion open to contributors and users. The project has no foundation,
formal committee, or elected roles.

The public decision process uses issues and pull requests in
https://github.com/nk2580/brr. A pull request can be merged after maintainer
review when its purpose, behavior, checks, and license attribution are clear.
Breaking changes and changes to authentication,
workspace access, or the owned runtime policy should receive an explicit issue
or pull request discussion before merge.

This lightweight process can evolve as the contributor community grows. Any
governance change will be documented here before it takes effect.
