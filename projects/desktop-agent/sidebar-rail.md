# Persistent desktop rail and collapsible sidebar

Delivered 2 November 2026 against the user's attached ChatGPT desktop reference.

The 52px icon rail stays visible in both layouts. It contains exactly Home, Agents and Plugins at the top, then the user profile avatar followed by a Settings gear at the bottom. All five controls have hover and keyboard-focus tooltips. Home returns to the current conversation and preserves its draft; repeated Agents, Plugins and Settings clicks stay in the selected section. Only the dedicated toolbar control toggles the adjacent sidebar; the chat occupies the released space when collapsed. The toolbar reserves room for native macOS window controls. Reference colors were sampled from the attachment: #191d22 for the rail/toolbar and #12151b for the sidebar, represented as OKLCH tokens. The sidebar is 330px wide at the reference desktop size, with narrower widths at the native minimum. Brr keeps its own name and working destinations.

The sidebar includes New chat, Search, Open project, folder disclosures with indented project conversations, and Recents. Projects are derived from saved thread project paths, using the original project for worktree sessions. The sidebar list scrolls independently of the rail, account controls and chat. Long names truncate. Search focuses its input, including repeated activation. Settings stays available while collapsed; closing it restores focus to its rail control. The profile avatar opens a nonmodal profile menu without changing sidebar visibility. Its initials use the separate parts of the account name when available. Escape or Close profile dismisses it and restores focus to the avatar; clicking outside dismisses it. Selecting a chat closes auxiliary panels and displays the transcript.

The adjacent menu follows the selected main section: Home projects/chats, Agents' agent list, or Plugins' plugin/MCP categories. The toolbar's accessible controls reference targets the active menu. Agents and Plugins reserve the responsive menu width within their section, and collapsing hides their menu and releases that space to their content. Home's menu is hidden in those sections. Collapse state is shared when switching sections, while the current chat draft remains intact.

Graphite is the default. Settings > Appearance > Rail color applies the selected color to the permanent 52px rail only. Home, Agents and Plugins collapsible menus keep their neutral dark background, and the chat and toolbar retain their own surfaces. Rail icons, hover, selection and focus use the selected palette. The existing eight alternatives, storage key and explicit saved selections remain supported. Collapse and color preferences persist on this device. Toggling layout preserves the message draft and active transcript; drafts are not newly persisted across application quits.
