# Persistent desktop rail and collapsible sidebar

Delivered 2 November 2026 against the user's attached ChatGPT desktop reference.

The 52px icon rail stays visible in both layouts. It contains exactly Home, Agents and Plugins at the top, then the user profile avatar followed by a Settings gear at the bottom. All five controls have hover and keyboard-focus tooltips. Home returns to the current conversation and preserves its draft; repeated Agents, Plugins and Settings clicks stay in the selected section. Only the dedicated toolbar control toggles the adjacent sidebar; the chat occupies the released space when collapsed. The toolbar reserves room for native macOS window controls. Typography and neutral surfaces follow the public site: locally bundled Archivo for UI, shared ink/charcoal surface roles, warm paper text and the saved paired rail/toolbar palette. See [shared theme](theme-cohesion.md). The sidebar is 330px wide at the reference desktop size, with narrower widths at the native minimum. Brr keeps its own name and working destinations.

The sidebar includes New chat, Search, Open project, folder disclosures with indented project conversations, and Recents. Projects are derived from saved thread project paths, using the original project for worktree sessions. The sidebar list scrolls independently of the rail and chat. It has no account footer; email, authentication and reconnect controls live on Profile. Long names truncate. Search focuses its input, including repeated activation. Settings stays available while collapsed; closing it restores focus to its rail control. The profile avatar opens a full Profile page in the workspace beside the rail, showing the account email and existing authentication actions. Its initials use the separate parts of the account name when available. Profile hides contextual menus while preserving their saved collapse state. Escape or Close profile returns to the previous section and restores focus to the avatar; repeated Profile activation stays on the page. The rail remains available for navigation. Selecting a chat closes auxiliary pages and displays the transcript.

The adjacent menu follows the selected main section: Home projects/chats, Agents' agent list, or Plugins' plugin/MCP categories. The toolbar's accessible controls reference targets the active menu. Agents and Plugins reserve the responsive menu width within their section, and collapsing hides their menu and releases that space to their content. Home's menu is hidden in those sections. Collapse state is shared when switching sections, while the current chat draft remains intact.

The graphite workspace has a 14px outer top-left corner that reveals the selected rail and toolbar colour. Collapsed Home and the Profile, Agents and Plugins pages clip their contents to the same curve; expanded Home keeps the inner sidebar/chat seam flush. The corner correction passed all 10 sidebar layout checks, Sol review, the production build and signature verification. Browser captures show both sidebar layouts; see [corner verification](evidence/sidebar-rail/rounded-corner-verification.json).

Graphite is the default. Settings > Appearance > Theme color applies the selected color to the permanent 52px rail and the full top toolbar together. Home, Agents and Plugins collapsible menus keep their neutral dark background, and the chat retains its own surface. Rail and toolbar icons, hover and focus use the selected palette; disabled toolbar controls remain visibly distinct. The existing eight alternatives, storage key and explicit saved selections remain supported. Collapse and color preferences persist on this device. Toggling layout preserves the message draft and active transcript; drafts are not newly persisted across application quits.
