# Artwork and type

The artwork was made with the built-in image generation tool, then encoded to
responsive WebP files with cwebp. Core navigation, copy, diagrams' explanations
and product-tour controls are semantic HTML. No generated UI screenshot is
shipped as an interface.

- `public/assets/rainbow-wood-chevrons.webp` (1536 × 1024) and
  `public/assets/rainbow-wood-chevrons-small.webp` (768 × 512): generated
  rainbow chevrons in matte painted birch plywood, with a clean transparent
  alpha channel. Final prompt: [hero-rainbow-wood.prompt.md](artwork/hero-rainbow-wood.prompt.md).
- `public/assets/extensible-harness.webp` (960 × 640) and the 480px variant:
  decorative connected skill/tool/source modules. Final prompt: "Three tactile
  rounded-square modules joined by curved rainbow tubes in a triangular loop.
  Pink top module with inset cog, cyan lower-left module with three-node
  network, yellow lower-right module with code brackets. Grainy solid resin
  and bold lighting. No words, letters, numbers, labels, UI or background.
  True transparent alpha."
- The extension artwork used the approved Rainbow Operator mock as its
  reference. The hero was regenerated from the earlier chevron motif with a
  painted-wood direction. Discarded probes and the generated website mock are
  not production assets.
- Archivo Latin variable font is self-hosted in `public/assets/fonts` from
  Google Fonts, with its unmodified SIL Open Font License in `OFL.txt`.
- UI icons use lucide-react. The favicon is an original code-native chevron
  mark. Paperclip's wordmark, logos, artwork and marketing copy are not included.
