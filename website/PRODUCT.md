# Brr marketing

Register: brand. This is a single-page introduction to Brr, separate from the quiet native desktop interface.

Brr is an open-source, extensible desktop agent harness for people researching, writing, organising, making and developing. Introduce what a harness means in ordinary language: a place for an agent to work with your project, tools and instructions. The first release uses managed ChatGPT sign-in and a bundled source fork of Codex CLI. Workspace tools and conversation storage are local; inference goes to OpenAI. The Plugins interface supports marketplaces, installing plugins, hooks and MCP connections.

Lead with personal agency and adaptable work, then invite visitors to extend and contribute. Open source means forkable code and an open contribution process. Do not imply a foundation, established contributor community, community legal ownership, hosted collaboration service, third-party inference providers or features not present in the app. Brr begins as an early, maintainer-led project. Apache 2.0 is approved for Brr's own code; preserve upstream notices.

Paperclip.app is the explicit brand reference: bold type, high contrast, colourful physical agent imagery, direct copy and a clear product demonstration. Brr's own voice is energetic, tactile and self-directed. The artwork should feel like 'agents go brr!' through a forward-moving rainbow swarm. Avoid generic AI dashboards, fake metrics, testimonials, prices and invented download/source links. The website preview embeds the actual desktop frontend with sample workspace data; it does not start an agent or perform inference. There is currently a locally built macOS app, with no public notarized download. Use truthful build instructions and a source-release status.
